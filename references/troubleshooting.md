# Troubleshooting

| Problem | What to do |
|---|---|
| No ffmpeg on the machine (`run_all.py` prints `NO_FFMPEG`; `qa.py: no ffmpeg on PATH (nor in /opt/homebrew/bin or /usr/local/bin)`) | Do not stop. Offer to install ffmpeg (Windows: `winget install Gyan.FFmpeg`; Mac: `brew install ffmpeg`). If the installed build has no libx264, use rung b (PNG frames, then AV1 MP4 or VP9 WebM with the colour chain, `engine.md`); make a GIF preview (rung c) if nothing else works. Tell the user which rung and that older QuickTime may not play AV1 or VP9. `qa.py approve`, `verify`, `audiostrip` and Q903's start-time read call ffmpeg by name, so put its folder on PATH. |
| A fact or a media file is needed mid-build | Render scripts download nothing. Fetch facts with the agent's web tools first and ask the user for any media, then pass the files in. Everything else (frames, synthesized audio, encode) works offline. |
| `PROOF: NOT CHECKED (n)` or `QA: NOT CHECKED (n)` (exit 2) | A gate had nothing to look at where something was expected. Read each NOT CHECKED row's fix: add `text_items(t)` (Q200, Q205, Q206, Q209), name the cues `CUES` (Q902; a kit's `CUE` is not read), rebuild a cue sheet that lost its stems (`run_all.py audio`), or declare `NO_TEXT`, `NO_CUES` or `SILENT` when there is none by design. It is not a pass: `run_all.py` rejects the file. |
| `NOT CHECKED Q100 <module> raised <Error> at <file>:<line>: ...; its gates did not run` | A gate module crashed; the other modules still ran. Import the module and call its `check_rows` alone to see the traceback. `qa.py: <module> did not import (...)` on stderr means its flags or subcommands are missing too. |
| `REJECTED out.rejected.mp4: Q502 FIX, ...` | The file failed those rows and is never delivered. Fix each one (the row's fix after `->`; `qa.py owner --t <worst_t>` names the scene function to re-read), then run again: `run_all.py audio` for an audio-only fix, `full` for a visual one. |
| `UNCHECKED out.unchecked.mp4: the run broke before the QA verdict (the error follows)` | A crash is not a verdict. Fix the error printed after it and run the stage again. |
| `ffmpeg stopped after 53 of 225 frames (exit 0): ...` | ffmpeg's own exit code and first log lines: read them (a bad option, a full disk, a frame it could not take). No partial `video.mp4` is left. |
| `ValueError: frame 5 (t 0.167 s) is 1922x1080; the build is 1920x1080` | draw(t) returned the wrong size at that frame (one such frame shears every frame after it). Return `finish(img)`, which scales to `E.W x E.H`. |
| `ffmpeg exited 0 but logged errors: ...` | Treated as a failed render (a short buffer, a bad packet). Fix what the log names. |
| `note: frame 40 drawn again after OSError: [WinError 1450] ...` | The system was short of resources for a moment (several builds at once); the frame was drawn again and the render went on. Six refusals of one frame, or `write to ffmpeg failed while it was running (frame k of n, 40 retries)`, stop it: run fewer builds or fewer processes at once (`run_all.py full 4`). |
| `video.mp4 predates scenes.py: frame 0 (0.00 s) and 8 more of 9 checked differ ...` or `video.mp4 was rendered at ...` (from `run_all.py audio`) | The picture is from another state of scenes.py, or another size: run `run_all.py full`, or give `audio` the same `--size`, `--fps` and `--ss` as the render. |
| `true peak still over -1 dBTP after 3 re-masters: lower the hits Q802 names` | Lower the raw gain of the sounds the Q802 row lists at that moment, first in its cut order. A lower ceiling makes the limiter work harder (Q805), so it is not the fix. |
| `a 0.05 MB budget leaves no video bitrate for 7.5 s with 320 kb/s of audio` | The budget cannot hold the audio for that length. Raise it, shorten the piece, or ask where the file goes and what its real limit is (`qa-gates.md`, gate 10). |
| `--redraw needs --keep-frames ...` or `frames/ lacks 195 of the frames to reuse ...` | Run `run_all.py full --keep-frames` once with no `--redraw`; then `--keep-frames --redraw T0-T1` redraws one passage. |
| `warning: STATIC (0.333333, 1) s moves (frame 20 differs from frame 10): every frame of it is drawn` | That span is not static. Take it out of `STATIC` or narrow it to frames that truly hold. |
| `qa.py purity` NOT CHECKED: `timed out after 240 s`, or `the pool pass waited 240 s for one frame (a worker died or hung)` | An environment failure (memory, a dead worker), not code to fix: report the command and that line. |
| `REFUSED: ...` or `CANNOT APPROVE: ...` from `qa.py approve` | It refuses a missing review, REVIEW FIX, a proof-stage review, a review of another file or of a file written at another time, and a qa.json with FIX or NOT CHECKED rows; it cannot approve without frames.hash from this source and size. Fix the cause and approve again; `--override "<why>"` only with a reason the user accepts (it is recorded and shown by every check). |
| `NOT CHECKED Q1304 environment changed since approval ...` or `DIFF: NOT CHECKED (could not compare ...)` | The frame size changed, or a Python, Pillow, numpy or font change moved frames: review the film in full, then approve again. |
| `refused: . holds a build (...)` from `qa.py calib` | Run it in its own folder (the default `calib/`). |
| `SELFTEST: FAIL (...)` | A gate no longer catches its planted fault (`MISSED`, `WRONG`), or a code is unproven (`MISSING`, `EMPTY`, `UNCOVERED`, `ERROR`): the line names the code and the fixture. Do not trust that gate on a build until it passes again. Every fixture `MISSING` means the engine copy lacks `qa_fixtures/` (copy it with `cp -r engine/. <folder>/`). |
| A text-to-speech download link expired | Generate the line again and save the file to the working folder as soon as it is ready. |
| Only the SAPI fallback is installed (robotic), or `voice engine kokoro-ts is not ready (...). Missing: ...` | Music with captions, or SAPI for a timing draft; on a new machine download the Kokoro model and voices with the user's yes (`voice.md` lists every file and its sha256 source). Say plainly that there is no natural voice yet and why. |
| `sapi wrote unusable audio: L02 (<path>.wav, deleted, not cached): no speech above -48.0 dBFS ...` | The engine wrote silence for that line (SAPI does for "..."): fix the line's text. Nothing was cached, so the next run asks the engine again. |
| `word_cue: 'square' is in L02, which has no word times ...`, `... is not in the narration ...; close words: ...` or `... has a time shared out between its neighbours ...` | Use an engine with word times (sapi, kokoro-ts) or cue the line start; fix the spelling from the close words; cue a word the voice says alone, or pass `est=True` knowing the time is a guess. |
| The voice reads names wrongly, or `Q806 ... 'Kalchar' is heard as 'Culture'` | Respell it with `voice.synthesize(..., lexicon={"Kalchar": "Kul char"})`: the engine reads the respelling, the screen and `word_cue` keep the real spelling. Run `qa.py speech` again, and ask the user to listen to those lines. |
| `FIX Q806 L02 missing 'national'` (or `extra`, or `heard as` an unrelated word) | The voice skipped, added or changed a word, or the line is not what the script says: listen to the line at the time given, fix the text or respell, synthesize again. A NOTE (close in letters, or a short word) is the voice or the model: listen and decide. |
| `NOT CHECKED Q806 the speech model is not ready (...)` | `python qa_speech.py fetch` (147.8 MB, MIT; Sagar's yes on a new machine), then check again. |
| `FIX Q807 the file's sound does not carry narration.wav (best match z ...)` | The mix is from an older take, was made without the narration, or buries it under the music: run `run_all.py audio` after the last `voice.synthesize`, and keep the voice above the bed (`voice.duck_mix`). |
| `NOTE Q807 L03: 'it today' is heard as 'the chain' in the file` | The music masks those words at that time: duck the bed deeper there, lower the sounds placed on the words, or lift the voice. |
| `ValueError: L04: ... would need speed 1.34 to fit 3.6 s (FIT_FAST 1.2): cut about 2 of its 10 words` | The line is too long for its storyboard time: cut the words it names, or give the line more time. Never raise `FIT_FAST` to make it fit. |
| A font is missing on the device | List C:/Windows/Fonts (Windows) or /System/Library/Fonts and /Library/Fonts (Mac), pick the nearest installed font, tell the user which one we used. Never silently fall back to the PIL default font. |
| Render is slow | Frames are drawn in parallel and piped into the encode; the draw is the cost (3 ms to about 360 ms a frame). Proof first at the real size; for a quick look render a slice (half size, `--fps 15`, or a 5 s passage) and check that. Draw at `SS 1` and supersample only the scenes with thin lines, cache static backgrounds as images, declare true holds in `STATIC`, keep grain and blur out of the preview, and keep the frames (`--keep-frames`) when passages will be redrawn. |
| Run times out | The full render is one call: frames go straight into one encode, so it cannot be split into batches. Time a slice first, give the call a timeout that covers the whole film, and if a tool limit cannot, stop and report it; never deliver a partial file. With `--keep-frames` a rerun redraws only the passages given with `--redraw`. |
| Out of disk or memory | Check `shutil.disk_usage`. Frames are on disk only with `--keep-frames` (about 1.3 GB per 60 s at 1080p); delete `frames/` once the file is verified. For memory, run fewer processes (`run_all.py full 4`) or a lower SS; a memory squeeze during the render redraws that frame. |
| Encode result fails a gate | Change one thing at a time: loudness (`audio.master`, Q805), size (CRF, a budget or resolution), duration (fix DURATION or the scene lengths), then run again and measure. Do not deliver a file that failed a gate without telling the user. |
| `PLATE:` line from `run_all.py`, or a 3D render that fails | A 3D plate is missing, stale, unfinished, being rendered or of proof quality: run the command the line ends with. The table at the end of `plates.md` has the other 3D cases (Blender not fetched, a cleaned uv cache, a render on the CPU) |
| `<name> is not cached` from `sampler.py` | The score plays a recorded instrument that is not downloaded: `python sampler.py fetch <name>` in the parent session (the builder cannot download), or score that part with the synth kit and say so |
| Session tab does not show the video | Share the file path, and show the poster PNG and the proof sheets instead. |
| Time is running out | Deliver what is verified (a shorter cut or the GIF preview), and list what is still open in "Known weak spots". |
